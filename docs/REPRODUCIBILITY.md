# Reproducibility Checklist

1. Catat build/version MetaTrader 5.
2. Catat server Exness yang digunakan.
3. Catat nama simbol persis seperti yang tampil di Market Watch karena nama indeks/komoditas dapat berbeda antar-server.
4. Catat timeframe.
5. Catat initial deposit, currency, dan risk per trade.
6. Catat tanggal dan jam pengujian.
7. Simpan screenshot Strategy Tester Settings.
8. Simpan screenshot tab Results/Graph/Report.
9. Export report HTML/CSV jika tersedia.
10. Simpan file `.set` parameter final.
11. Jangan memasukkan username, password, API key, atau kredensial akun ke repository.
